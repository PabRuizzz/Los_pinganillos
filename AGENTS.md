# Minijuegos

- Crear los nuevos minijuegos como escenas independientes con nodos persistentes y visibles en el editor 2D, para que frontend pueda mover elementos y asignar imágenes y assets desde el Inspector.
- Usar escenas reutilizables para piezas, casillas y elementos repetidos; incluir nodos visuales como Artwork y mantener la lógica separada de la presentación.
- Para los minijuegos con Camera2D, mantener la interfaz fija en CanvasLayer y verificar las interacciones con desplazamiento y zoom.
