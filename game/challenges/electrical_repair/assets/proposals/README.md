Generada con la herramienta integrada image_gen. Aprobada por el usuario e integrada mediante recursos AtlasTexture. El atlas es una propuesta visual: casilla vacía, bloqueo, entrada, salida, once tipos de cable y una muestra energizada. Exterior transparente, sin decoración fuera del tablero.

Archivo: sci_fi_tiles_v1.png. El original de propuesta se conserva aquí; las escenas usan assets/sci_fi_tiles.png y sus recortes .tres.

## Prompt utilizado

Use case: stylized-concept. Asset type: proposal sprite atlas for a Godot sci-fi electrical cable puzzle. Generate a polished 4 by 4 sprite sheet, exactly 16 equally sized square game tiles aligned to a strict regular grid with generous transparent gutters. True transparent background outside the tiles. Strict flat orthographic top-down view, no perspective. Inspired by classic Pipe Mania metal floor tiles with chunky cables and visible seams, reimagined as a futuristic spacecraft maintenance panel. Readable at small size, restrained industrial sci-fi, graphite blue-gray metal, brushed steel beveled edges, small screws, cable insulation pale silver with narrow cyan energy channels. No text, no letters, no watermark, no UI, no scenery or decorations outside the individual tiles. Each tile has the same square metal base, a thin clean border, a single clear thick cable conduit where specified. Cable connectors end exactly at the midpoint of each required edge. Cables must never branch except T and cross. Layout row 1 left to right: empty metal cell; blocked cell with recessed dark X and small amber hazard corners; green power source terminal with right-facing socket; amber destination terminal with left-facing socket. Row 2: west-east straight cable; north-south straight cable; north-east elbow; north-west elbow. Row 3: south-east elbow; south-west elbow; T with north-east-south connections; T with north-east-west connections. Row 4: T with north-south-west connections; T with east-south-west connections; cross with all four connections; energized west-east straight cable glowing green. Maintain consistent proportions, tile edges, light source and connector widths across all 16 tiles. Professional 2D game asset concept atlas for approval, not a screenshot or full puzzle level.
